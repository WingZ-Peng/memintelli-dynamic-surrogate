# 理想电导动态代理模型的范围约定

> 本文由英文版 [`DESIGN.md`](DESIGN.md) 翻译而来。**如有出入，以英文版为准。**

## 建模目标

本实验建模的是**一个**确定性的、理想编程状态下的电导：

```text
weight -> quantization/slicing -> G_ideal
G_ideal + dynamic read/voltage noise + ADC -> output distribution
```

写入变异与固定故障已被关闭。它们既不是模型输入，也不属于目标分布。因此所学习的分布是 `p(Y | X, G_ideal, hardware_config)`，而不是器件总体（device population）模型。

## 各预测头的输入

所有特征都是当前输入、`G_ideal`、固定布局与硬件配置的确定性函数。

- **均值**：量化后的电压、理想电导/电平、理想 ADC 状态、ADC 裕度，以及对数正态读取噪声在 ADC 之前引起的解析均值偏移。
- **方差**：电压/电导的平方能量、ADC 之前的解析噪声方差、ADC 跳变灵敏度，以及局部噪声源载荷能量。
- **相关性**：归一化的电压/读取噪声源载荷特征、理想电压/电平几何关系、ADC 灵敏度，以及坐标与布局的身份信息。

任何一个预测头都不会接收到实现出的 `G_static`、写入种子或随机采样轨迹。

## 噪声层次

对确定性的理想单元电导 `g` 与量化电压 `v`：

```text
V_read = v * (1 + Normal(0, sigma_v))
G_read = g * exp(Normal(0, sigma_r))
pre_adc = sum(V_read * (G_read - LGS))
```

特征构造使用的是该模型在 ADC 之前的前两阶**精确**矩。相关性的噪声源载荷使用局部 ADC 跳变增益；相关性预测头则是建立在这些物理噪声源之上的因子模型：它以闭式解析载荷为初始值，学习一个有界的修正量，外加每个坐标各自的可解释方差占比。

## 范围边界

这个单一的验证性实验回答的问题是：在**一个**固定的权重与配置下，三个动态预测头能否泛化到未参与训练的输入。它**不**检验写入变异、新的权重、新的形状、新的布局，也不检验新的硬件配置。
